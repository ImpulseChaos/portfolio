# Kayhaan Rashiq — Portfolio

Personal portfolio site built with Next.js and Tailwind CSS. Features a custom synthwave hero canvas animation, dark/light mode, and sections for About, Projects, Skills, and Contact.

## Stack

- [Next.js](https://nextjs.org) (App Router)
- [Tailwind CSS](https://tailwindcss.com)
- [next-themes](https://github.com/pacocoursey/next-themes)
- Deployed on [Vercel](https://vercel.com)
